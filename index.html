Modal

배경 오버레이 위에 다이얼로그를 띄우는 컴포넌트. ESC/오버레이 클릭 닫기, 포커스 트랩, 배경 스크롤 락을 지원합니다.

라이브 데모

샘플 모달

이 모달은 다음 기능을 지원합니다:

  • ESC 키로 닫기
  • 오버레이(배경) 클릭으로 닫기 — 이 박스를 클릭해도 닫히지 않음
  • Tab / Shift+Tab 포커스 트랩
  • 배경 스크롤 락
  • 닫을 때 이전 포커스 요소로 복귀

Accordion

클릭 또는 방향키로 항목을 펼치고 접는 컴포넌트. WAI-ARIA 아코디언 패턴의 키보드 탐색을 지원합니다.

라이브 데모

별도 프레임워크 없이 순수 JavaScript(ES 모듈)로 작성되었습니다. 모든 컴포넌트는 공통 베이스 클래스인 Component를 상속받아 옵션 병합, 이벤트 발행, 리스너 정리를 동일한 패턴으로 처리합니다.
네. WAI-ARIA 아코디언 패턴을 따릅니다. ArrowDown/ArrowUp으로 트리거 간 포커스를 순환 이동하고, Home/End로 첫/마지막 트리거로 바로 이동할 수 있습니다.
기본값은 false라서 하나를 열면 나머지가 자동으로 닫힙니다. 위 "multiple" 체크박스를 켜면 여러 항목을 동시에 열어둘 수 있습니다.
height: auto는 트랜지션이 되지 않기 때문에, 열 때는 scrollHeight로 실제 픽셀 높이를 계산해 트랜지션한 뒤 완료 시점에 height: auto로 전환합니다. 닫을 때는 반대 순서로 진행됩니다.

Tabs

탭 목록 중 하나를 선택해 해당 패널을 표시하는 컴포넌트. 방향키 이동 시 즉시 활성화되는 automatic activation 패턴을 따릅니다.

라이브 데모

Tabs는 Component 베이스 클래스를 상속받아 Modal, Accordion과 동일한 패턴(옵션 병합, emit을 통한 이벤트 발행, destroy 시 리스너 일괄 해제)으로 동작합니다.
new Tabs('#myTabs', { activeIndex: 0, onChange }) 형태로 생성하고, select(index) 메서드로 원하는 탭을 프로그래밍 방식으로 전환할 수 있습니다.
WAI-ARIA 탭 패턴의 자동 활성화(automatic activation) 방식을 따릅니다. 방향키로 포커스를 옮기면 별도의 Enter/Space 없이 즉시 해당 패널이 활성화됩니다.

Dropdown

버튼을 눌러 옵션 목록을 펼치는 커스텀 셀렉트 컴포넌트. W3C APG의 Collapsible Dropdown Listbox 패턴을 따릅니다.
