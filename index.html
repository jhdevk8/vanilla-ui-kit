Modal

배경 오버레이 위에 다이얼로그를 띄우는 컴포넌트. ESC/오버레이 클릭 닫기, 포커스 트랩, 배경 스크롤 락을 지원합니다.

라이브 데모

샘플 모달

이 모달은 다음 기능을 지원합니다:

  • ESC 키로 닫기
  • 오버레이(배경) 클릭으로 닫기 — 이 박스를 클릭해도 닫히지 않음
  • Tab / Shift+Tab 포커스 트랩
  • 배경 스크롤 락
  • 닫을 때 이전 포커스 요소로 복귀
이벤트 로그가 여기에 표시됩니다.

초기화 코드

const modal = new Modal('#demoModal', {
  closeOnEsc: true,
  closeOnOverlayClick: true,
  onOpen: () => {},
  onClose: () => {},
});

modal.open();
modal.close();
modal.toggle();

Options

이름타입 / 기본값설명
closeOnOverlayClickboolean, 기본 true오버레이(배경) 클릭 시 모달을 닫을지 여부
closeOnEscboolean, 기본 trueESC 키 입력 시 모달을 닫을지 여부
onOpen / onClosefunction모달이 열리거나 닫힐 때 호출되는 콜백

Events

이벤트명detail설명
modal:open—모달이 열렸을 때 발행
modal:close—모달이 닫혔을 때 발행

Accordion

클릭 또는 방향키로 항목을 펼치고 접는 컴포넌트. WAI-ARIA 아코디언 패턴의 키보드 탐색을 지원합니다.

라이브 데모

별도 프레임워크 없이 순수 JavaScript(ES 모듈)로 작성되었습니다. 모든 컴포넌트는 공통 베이스 클래스인 Component를 상속받아 옵션 병합, 이벤트 발행, 리스너 정리를 동일한 패턴으로 처리합니다.
네. WAI-ARIA 아코디언 패턴을 따릅니다. ArrowDown/ArrowUp으로 트리거 간 포커스를 순환 이동하고, Home/End로 첫/마지막 트리거로 바로 이동할 수 있습니다.
기본값은 false라서 하나를 열면 나머지가 자동으로 닫힙니다. 위 "multiple" 체크박스를 켜면 여러 항목을 동시에 열어둘 수 있습니다.
height: auto는 트랜지션이 되지 않기 때문에, 열 때는 scrollHeight로 실제 픽셀 높이를 계산해 트랜지션한 뒤 완료 시점에 height: auto로 전환합니다. 닫을 때는 반대 순서로 진행됩니다.
이벤트 로그가 여기에 표시됩니다.

초기화 코드

const accordion = new Accordion('#myAccordion', {
  multiple: false,
  defaultOpen: 0,
  onToggle: ({ index, isOpen }) => {},
});

accordion.open(index);
accordion.close(index);
accordion.toggle(index);

Options

이름타입 / 기본값설명
multipleboolean, 기본 false여러 항목을 동시에 열어둘 수 있는지 여부
defaultOpennumber | number[]초기에 열려 있을 항목의 인덱스(들)

Events

이벤트명detail설명
accordion:toggle{ index, isOpen }항목이 열리거나 닫힐 때 발행

Tabs

탭 목록 중 하나를 선택해 해당 패널을 표시하는 컴포넌트. 방향키 이동 시 즉시 활성화되는 automatic activation 패턴을 따릅니다.

라이브 데모

Tabs는 Component 베이스 클래스를 상속받아 Modal, Accordion과 동일한 패턴(옵션 병합, emit을 통한 이벤트 발행, destroy 시 리스너 일괄 해제)으로 동작합니다.
new Tabs('#myTabs', { activeIndex: 0, onChange }) 형태로 생성하고, select(index) 메서드로 원하는 탭을 프로그래밍 방식으로 전환할 수 있습니다.
WAI-ARIA 탭 패턴의 자동 활성화(automatic activation) 방식을 따릅니다. 방향키로 포커스를 옮기면 별도의 Enter/Space 없이 즉시 해당 패널이 활성화됩니다.
이벤트 로그가 여기에 표시됩니다.

초기화 코드

const tabs = new Tabs('#myTabs', {
  activeIndex: 0,
  onChange: ({ index }) => {},
});

tabs.select(index);

Options

이름타입 / 기본값설명
activeIndexnumber, 기본 0초기에 활성화될 탭의 인덱스
onChangefunction활성 탭이 바뀔 때 호출되는 콜백

Events

이벤트명detail설명
tabs:change{ index }활성 탭이 바뀌었을 때 발행

Dropdown

버튼을 눌러 옵션 목록을 펼치는 커스텀 셀렉트 컴포넌트. W3C APG의 Collapsible Dropdown Listbox 패턴을 따릅니다.

라이브 데모

    이벤트 로그가 여기에 표시됩니다.

    초기화 코드

    const dropdown = new Dropdown('#myDropdown', {
  options: [
    { value: 'apple', label: '사과' },
    { value: 'banana', label: '바나나' },
  ],
  placeholder: '과일을 선택하세요',
  onSelect: ({ value, label }) => {},
});

dropdown.select(value);
dropdown.open();
dropdown.close();

    Options

    이름타입 / 기본값설명
    optionsarray{ value, label } 형태의 옵션 목록. 주어지지 않으면 마크업에 있는 .dropdown-option을 그대로 사용
    placeholderstring선택된 값이 없을 때 트리거에 표시할 문구
    onSelectfunction옵션을 선택했을 때 호출되는 콜백

    Events

    이벤트명detail설명
    dropdown:select{ value, label }옵션을 선택했을 때 발행

    Carousel

    여러 슬라이드를 좌우로 전환하는 컴포넌트. 자동재생, 드래그/스와이프, 인디케이터 클릭을 지원합니다.

    라이브 데모

    슬라이드 1
    슬라이드 2
    슬라이드 3
    슬라이드 4
    슬라이드 5
    이벤트 로그가 여기에 표시됩니다.

    초기화 코드

    const carousel = new Carousel('#myCarousel', {
  autoplay: true,
  interval: 3000,
  loop: true,
  startIndex: 0,
  onChange: ({ index }) => {},
});

carousel.next();
carousel.prev();
carousel.goTo(index);
carousel.play();
carousel.pause();

    Options

    이름타입 / 기본값설명
    autoplayboolean, 기본 false생성 직후 자동재생을 시작할지 여부
    intervalnumber, 기본 3000자동재생 슬라이드 전환 간격(ms)
    loopboolean, 기본 true마지막 슬라이드에서 다음으로 넘길 때 처음으로 순환할지 여부
    startIndexnumber, 기본 0초기에 표시할 슬라이드 인덱스
    onChangefunction슬라이드가 바뀔 때 호출되는 콜백

    Events

    이벤트명detail설명
    carousel:change{ index }슬라이드가 바뀌었을 때 발행

    Toast

    기존 요소에 붙지 않고 스스로 컨테이너를 만들어 body에 삽입하는 매니저 패턴 컴포넌트. 짧은 알림 메시지를 큐잉하며 표시합니다.

    라이브 데모

    이벤트 로그가 여기에 표시됩니다.

    초기화 코드

    const toast = new Toast({
  position: 'top-right',
  duration: 3000,
  maxVisible: 3,
});

toast.show('저장되었습니다', { type: 'success' });
const id = toast.show('처리 중...', { type: 'info', duration: 0 }); // duration 0 → 수동 dismiss 전까지 유지
toast.dismiss(id);
toast.clear();

    Options

    이름타입 / 기본값설명
    positionstring, 기본 'top-right'컨테이너 위치. top/bottom × left/center/right 조합 6가지
    durationnumber, 기본 3000토스트가 자동으로 사라지기까지의 시간(ms). 개별 show()에서 오버라이드 가능
    maxVisiblenumber, 기본 3동시에 표시할 수 있는 최대 토스트 개수. 초과분은 큐에서 대기

    Methods

    이름설명
    show(message, itemOptions)토스트를 표시(또는 큐잉)하고 고유 id를 반환. itemOptions로 type('success'|'error'|'info'|'warning')과 duration을 개별 지정 가능
    dismiss(id)특정 토스트를 사라짐 애니메이션 후 제거. 큐에 대기 중이면 큐에서 제거
    clear()화면에 보이는 토스트와 대기 큐를 전부 제거

    Events

    이벤트명detail설명
    toast:show{ id }토스트가 화면에 표시됐을 때 발행
    toast:dismiss{ id }토스트가 제거됐을 때 발행
